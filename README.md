# WorkBoard

A project and task management platform designed for software development teams.

## Overview

WorkBoard is a portfolio and learning project focused on building a maintainable full-stack application while practicing software engineering fundamentals.

The project will evolve incrementally, starting with a TypeScript command-line application and progressing toward a complete web platform.

## Project goals

- Manage tasks and their lifecycle.
- Organize software development projects.
- Support team collaboration.
- Apply TypeScript and JavaScript fundamentals.
- Practice software architecture, testing, and documentation.

## Technology roadmap

- **Core:** TypeScript, Node.js
- **Backend:** Express, PostgreSQL
- **Frontend:** React, Vite, Tailwind CSS
- **Testing:** Vitest, React Testing Library, Supertest
- **DevOps:** GitHub Actions, Docker

## Current status

**Sprint 0 — Project setup**

The project is currently being initialized. Application functionality has not been implemented yet.

## Planned versions

- **v0.1:** TypeScript CLI and task management core.
- **v0.2:** REST API and database.
- **v0.3:** React web application.
- **v0.4:** Authentication, authorization and collaboration.
- **v1.0:** Production-ready portfolio release.
